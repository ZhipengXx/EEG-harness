Return one finding per distinct claim. topic identifies the scientific theme. statement describes what the paper reports, retaining the conditions, comparison and uncertainty that qualify the claim. Keep different experimental settings separate when their findings differ.

Use only information present in the supplied material; do not fill gaps using the current research configuration. All three setup keys are required, and null means the material does not report that information. If the material contains no relevant finding, return an empty findings list.

Return only the JSON described by OUTPUT_SCHEMA. Local code attaches paper identity and reading coverage. Recommendations for this project and candidate selection belong to Planner; return the paper's findings without adding those decisions.
